# Changelog

All notable changes to the OctoUniversalController system will be documented in this file.

## [2.4.2] - 2026-11-02
### Əlavə Edildi
- Sol altda tema rənglərinə uyğun dinamik dairəvi profil şəkli (Circle PFP) və canlı sessiya taymeri (Session Timer).
- Apple SF Pro şrift ailəsi (-apple-system, SF Pro Display / Text) bütün interfeys elementlərinə tətbiq edildi.
- GitHub üzərindən canlı versiya yoxlama və məlumatları zədələmədən təhlükəsiz yenilənmə mühərriki.
- Session lock ekranı və təhlükəsiz çıxış (logout) mexanizmi.

### Təkmilləşdirmələr
- Canlı qrafikdən süni "Live Stream (CDN Edge)" yazısı ləğv edildi və bütün statistika 100% real bazaya bağlandı.
- SQLite 3 tam backup və Adminer self-healing avtomatik bərpa mexanizmi gücləndirildi.
- 8 fərqli tema (Titanium Studio, Midnight OLED, Nordic Glacier, Emerald Sovereign, Tokyo Cyberpunk, Warm Amber, Crimson Dynasty, Abyssal Ocean) üzrə CSS dəyişənləri optimallaşdırıldı.
- Məlumat itkisinin qarşısını almaq üçün atomik fayl yazılışı (.tmp swap) tətbiq edildi.

## [2.4.0] - 2026-11-01
### Əlavə Edildi
- Çoxlu vərəq (multi-tab) iş sahəsi və Command Palette (CMD+K) sürətli naviqasiyası.
- SQLite 3 ikili verilənlər bazası ixracı və Adminer proksi inteqrasiyası.
- Çoxdilli lokalizasiya mərkəzi (AZ, TR, RU, EN).
